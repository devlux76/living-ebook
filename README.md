# living-ebook
An open-source project for creating interactive, AI-powered 'living ebooks' based on public domain texts, enabling users to engage with characters and explore the worlds within the books in a new way.

There are two parts to this repository.
##ebook-maker 
Allows you to create a living ebook from a public domain text.
At the moment it is specifically designed to accept the pdfs that are scanned images of the type provided by the internet archive.

It will generate the raw text output as a series of .txt files with one per page.

##ebook-reader
Is locally installable web based reader that interacts with the living ebooks generated by the ebook-maker.

You can query the text, chat with characters and explore the world of the book. 
If you don't like the way an event turns out, ask the book to change it and it will rewrite the text to reflect how you wanted it to go.

This is all experimental at the moment, but the idea is to create a new way of interacting with books that is more like a chat system than a traditional book.
